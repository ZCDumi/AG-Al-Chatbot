# Analytics Group — Website Chatbot

A guided chatbot for [analyticsgroup.co.za](https://analyticsgroup.co.za/) that helps site
visitors understand AG's services and points warm leads to a consultation. Built with a
**FastAPI** backend and a **React (Vite)** floating chat widget, styled to match a
"data alchemy" visual identity (deep ink base, burnished-gold accent) drawn from the
company's own tagline: *"Master the alchemy of people, tools, and strategy to turn big
data into a competitive advantage."*
